A web-based ERP system for managing student admissions, campus setup, role-based access, student records, and document workflows.

---

## 📌 Overview

The **School ERP Management System** replaces manual, paper-based processes with a centralized digital platform.

It helps manage:
- Student enquiries and admissions
- Campus and branch configuration
- Role-based access
- Student records
- Document workflows

---

## 🚀 Key Features

- Multi-step student enquiry and admission forms  
- Role-based access (Admin, Staff)  
- Campus, branch, and grade-based workflows  
- Document management system  
- REST API integration  
- Responsive UI with real-time updates  
- Search, filtering, and status tracking
